# Sales Pipeline & Lead Management System

## Files
- `Sales_Pipeline_Lead_Management.xlsx` — completed Excel workbook with tracker, dashboard, status summary and charts.
- `documentation/Project_Case_Study.md` — project write-up, KPI definitions, limitations and interview explanation.
- `documentation/Portfolio_Entry.md` — portfolio-ready project description.
- `hubspot_later/hubspot_import_sample.csv` — fictional data formatted for a future HubSpot import.
- `hubspot_later/HubSpot_Setup_Later.md` — checklist for the deferred CRM setup.

## Open the workbook
Open `Sales_Pipeline_Lead_Management.xlsx` in desktop Microsoft Excel. Visit Dashboard, Lead Tracker and Status Summary. Excel recalculates formulas when opened.

## Important honesty note
This is a completed Excel demonstration project using synthetic data. HubSpot signup/import and public deployment have not been completed. Do not claim that the workbook is connected to HubSpot or that sample metrics are real business outcomes.

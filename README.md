# Sales CRM & Lead Funnel

A portfolio-ready Excel-based CRM simulation for entry-level sales and business-development roles.

## Open the project
- `index.html` — portfolio website (enable GitHub Pages from the `main` branch, root folder).
- `Sales_Pipeline_Lead_Management.xlsx` — main workbook with Dashboard, Lead Tracker, Funnel Analysis, Call Playbook and How to Use.
- `CRM_Import_Template.csv` — sample CRM import field mapping for 50 fictional leads.
- `Inbound_Outbound_Call_Scripts.md` — practice call scripts and follow-up email.
- `Objection_Handling_Playbook.md` — ethical responses and checklist.
- `Project_Case_Study.md` — business problem, design, metrics and limitations.
- `Portfolio_Entry.md` — resume-ready project description.

## Key features
- 50 fictional business leads
- Stage and priority dropdowns
- Formula-driven follow-up flags
- Pipeline and won-value KPIs
- Stage distribution chart
- Call scripts and objection-handling guide

## How to use
1. Open the workbook in Microsoft Excel or a compatible spreadsheet app.
2. Update the sample lead stages and next follow-up dates.
3. Review the dashboard and funnel analysis.
4. Use the scripts for role-play practice; replace placeholders with an approved, truthful pitch.
5. Optionally import the CSV into a free CRM account if the account's current plan allows it.

## Data and claims
All sample company names, contact labels, values, stages and notes are fictional. This project is an Excel-based practice simulation. It is **not** a connected HubSpot/Zoho CRM and does not represent real sales outcomes.
